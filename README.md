# AURÉLUXE v2

A much larger luxury wallpaper-library frontend with:
- category navigation (Nature, Gaming, Luxury, Cars, Architecture, Minimal, Abstract, Space, Aesthetic)
- search
- 45 themed entries
- favorites stored in browser localStorage
- account UI
- premium-theme flow
- download controls
- responsive mobile design

## Important production step
This is a functional frontend, but it is not yet a secure multi-user production service. Real authentication, admin uploads, cloud storage, premium payments and a hosted database require a backend such as Supabase/Firebase plus deployment. The included account/favorites demo uses local browser storage.

The help feature intentionally does not publish a minor's personal phone number. Add a parent/guardian-controlled support contact when you deploy publicly.

Also replace third-party demo image URLs with wallpapers you own or are licensed to distribute before commercial launch.
